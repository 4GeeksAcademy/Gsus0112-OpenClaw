# Instrucciones
Cuando el usuario te pida anotar algo en su diario de aprendizaje:
1. Toma el texto o los apuntes proporcionados por el usuario.
2. Utiliza la herramienta de Zapier MCP conectada a Google Docs para crear un documento nuevo.
3. El título del documento DEBE ser "Diario de Jesús - [Fecha de hoy]".
4. El contenido debe estar formateado profesionalmente con viñetas, mejorando la redacción del usuario.
5. Una vez creado, notifica al usuario por Telegram usando tu tono directo y sin rodeos (según tu SOUL.md).
